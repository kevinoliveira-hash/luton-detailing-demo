## Genuine gallery photographs

The before-and-after gallery deliberately remains an interactive, clearly labelled
placeholder. Do not insert stock or generated photographs into comparison pairs.
Before replacing a placeholder, obtain permission to use genuine client work.
Each pair must depict the same vehicle and real work, with an accurate caption
and meaningful alternative text. Optimise approved files to WebP or AVIF, give
images explicit width and height, and lazy-load below-the-fold photographs.
Remove the photography-pending labels only after genuine photographs are supplied.
